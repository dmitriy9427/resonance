# 05. Шейдеры

## Что такое шейдер

Программа на языке **GLSL**, которая выполняется на видеокарте — параллельно
для тысяч точек. Их два вида:

- **вершинный** — для каждой вершины геометрии: куда её поставить на экране
  (`gl_Position`);
- **фрагментный** — для каждого пикселя: какого он цвета (`gl_FragColor`).

Связь с JavaScript — через **uniform'ы** (одинаковые для всех точек
значения: время, бас) и **атрибуты** (свои у каждой вершины: радиус звезды).
Из вершинного во фрагментный данные передаются через **varying**.

```tsx
const uniforms = useMemo(() => ({ uBass: { value: 0 } }), [])
useFrame(() => { uniforms.uBass.value = levels.bass })
<shaderMaterial uniforms={uniforms} vertexShader={v} fragmentShader={f} />
```

## «Пульс» (`Sphere.tsx`)

**Вершинный:** каждая вершина сдвигается вдоль своей нормали (направления
«наружу») на величину шума:

```glsl
float big = snoise(normal * 1.4 + time);       // крупные волны
float disp = big * (0.1 + uBass * 0.55) + …;   // высоту задаёт бас
vec3 pos = position + normal * disp;
```

**Simplex noise** — плавный шум: соседние точки дают похожие значения,
поэтому поверхность колышется, а не рябит. Подставляя в шум время, мы его
«прокручиваем» — волны бегут.

**Фрагментный:** эффект **Френеля** — края сферы (где поверхность почти
параллельна взгляду) светятся сильнее центра. Это даёт объём без источников
света: `pow(1.0 - dot(normal, view), 2.4)`. Тонкие линии — синусоида от
высоты волны, как изолинии на карте.

## «Галактика» (`Galaxy.tsx`)

60 000 точек (`<points>`), и **ни одна позиция не считается на процессоре**.
Каждой звезде при создании даны атрибуты: радиус, номер рукава, случайный
разброс. Вершинный шейдер каждый кадр:

1. поворачивает звезду: внутренние быстрее внешних (`uTime / (0.6 + r)`);
2. берёт громкость своей полосы спектра по радиусу (`uSpectrum[band]` —
   uniform-массив из 64 чисел);
3. выталкивает звезду из диска на эту громкость.

Цвет — палитра Иньиго Квилеса (`cos` со сдвигами — плавная радуга), смешение
**аддитивное**: где звёзд много, свет складывается — как в настоящей
галактике.

## «Горизонт» (`Terrain.tsx`)

Плоскость 128×128 вершин. Высоту вершины задаёт **текстура истории
спектра**: 64 столбца (полосы) × 128 строк (моменты времени). Каждый кадр
пишем новую строку по кругу (кольцевой буфер), шейдер читает со сдвигом —
и рельеф «едет» к зрителю.

```glsl
float level = texture2D(uHistory, vec2(band, row)).r;
```

Текстура — байтовая (0…255), а не float: плавную выборку из float-текстур
поддерживают не все телефоны.

Сетка рисуется во фрагментном шейдере через `fwidth` — изменение координаты
между соседними пикселями. Так линия всегда толщиной ~1 пиксель: и у камеры,
и у горизонта.

Солнце — круг с градиентом и прорезями (`fract(y * 14 + time)`). Его
яркость следит за басом **через очень медленное сглаживание**: в первой
версии солнце мигало на каждом ударе, и это выглядело как сбой, а не как
музыка.
