# Документация «Резонанса»

Учебник по проекту: от «что такое спектр» до шейдеров. Главы рассчитаны на
того, кто знает React, но не работал со звуком и 3D. Читать лучше по порядку.

| Глава | О чём |
| --- | --- |
| [01. Архитектура](01-architecture.md) | Из каких частей состоит проект и как данные идут от звука к картинке |
| [02. Звук в браузере](02-web-audio.md) | Web Audio API, спектр (FFT), полосы частот, детектор долей |
| [03. Демо-трек из кода](03-synth.md) | Как собрать музыку из осцилляторов и шума, точный ритм |
| [04. React Three Fiber](04-r3f.md) | three.js в React: Canvas, useFrame, почему уровни звука не в state |
| [05. Шейдеры](05-shaders.md) | GLSL с нуля на примере трёх сцен |
| [06. Свечение и производительность](06-post-and-perf.md) | Bloom, постобработка, 60 fps на слабых устройствах |
| [Шпаргалка к собеседованию](interview.md) | Вопросы по проекту и ответы |
