# 01. Архитектура

## Части проекта

```
src/
  audio/            звук — без React
    engine.ts       AudioContext, источники (демо, файл, микрофон), анализатор
    analysis.ts     чистые функции: полосы частот, сглаживание, детектор долей
    levels.ts       общий объект «что сейчас звучит» (обновляется 60 раз в секунду)
    song.ts         демо-трек как данные: аккорды, партии по шагам
    synth.ts        синтезатор, который озвучивает song.ts
  scenes/           3D на React Three Fiber
    Stage.tsx       <Canvas>, постобработка, выбор сцены
    Sphere.tsx      «Пульс»
    Galaxy.tsx      «Галактика»
    Terrain.tsx     «Горизонт»
    glsl.ts         общие куски шейдеров (шум, палитра)
  store/player.ts   Zustand: источник, пауза, сцена, громкость
  ui/               интерфейс поверх сцены: старт, плеер, клавиши
```

Правило: **звук не знает о React, 3D не знает, откуда звук.** Между ними —
один объект `levels`.

## Путь данных за один кадр

```
 динамики ◄── AnalyserNode ◄── источник (синтезатор / <audio> / микрофон)
                  │
                  │  getByteFrequencyData — 1024 числа 0…255
                  ▼
        engine.sample()  ─ полосы, сглаживание, доли ─►  levels
                                                           │
                    useFrame в каждой сцене читает levels ─┘
                    и меняет uniform'ы шейдеров
```

1. `AudioPump` (в `Stage.tsx`) раньше всех в кадре вызывает
   `audio.sample()`.
2. Движок берёт у анализатора спектр, считает бас, середину, верха,
   громкость, 64 полосы спектра и проверяет, не доля ли это.
3. Результат кладётся в `levels` — обычный изменяемый объект.
4. Сцены в своих `useFrame` читают `levels` и передают числа в шейдеры.
5. Видеокарта рисует кадр.

React в этом цикле **не участвует** — он перерисовывает только интерфейс,
когда меняется что-то редкое (пауза, сцена, трек). Подробнее — глава 04.

## Два вида состояния

| Что | Где | Как часто меняется |
| --- | --- | --- |
| Источник, пауза, сцена, громкость | Zustand (`store/player.ts`) | по клику |
| Уровни звука, спектр, доли | `levels` (`audio/levels.ts`) | 60 раз в секунду |

Если положить уровни звука в `useState`, React перерисовывал бы плеер 60
раз в секунду без пользы — кнопки от этого не меняются.
