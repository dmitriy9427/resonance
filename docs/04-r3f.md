# 04. React Three Fiber

## Что это

**three.js** — библиотека 3D для WebGL: сцена, камера, меши, материалы.
**React Three Fiber (R3F)** позволяет описывать сцену three.js как
React-компоненты:

```tsx
<Canvas>
  <mesh>
    <icosahedronGeometry args={[1.3, 48]} />
    <shaderMaterial vertexShader={...} fragmentShader={...} />
  </mesh>
</Canvas>
```

`<mesh>` — это `new THREE.Mesh()`, `args` — аргументы конструктора, а
остальные пропсы — свойства объекта (`position`, `rotation`). Компоненты из
`@react-three/drei` — готовые помощники (`<Stars>`, `<PerformanceMonitor>`).

## useFrame — сердце анимации

```tsx
useFrame((state, dt) => {
  mesh.current.rotation.y += dt * 0.1
})
```

Функция вызывается **каждый кадр** перед отрисовкой. `dt` — сколько секунд
прошло с прошлого кадра: умножая скорость на `dt`, получаем одинаковую
анимацию при 60 и 120 fps. `state` — камера, часы, рендерер.

Второй аргумент — приоритет. `AudioPump` вызывается с приоритетом −1, то
есть **раньше** сцен: к моменту, когда сцена читает `levels`, там уже
свежие данные этого кадра.

## Главное правило: в кадре — не setState

Анимация 60 раз в секунду через `useState` означала бы 60 перерисовок React
в секунду: сравнение виртуального DOM, вызовы всех дочерних компонентов.
Поэтому в R3F принято:

- **читать** изменяемые данные в `useFrame` (`levels.bass`);
- **писать** прямо в объекты three.js: `mesh.current.rotation.y = …`,
  `uniforms.uBass.value = …`, `geometry.attributes.position.needsUpdate = true`.

React перерисовывает сцену только когда меняется её **структура** — например,
сменили сцену в плеере.

## useMemo для тяжёлых объектов

Геометрия из 60 000 звёзд, текстура истории спектра, объект uniform'ов —
создаются один раз:

```tsx
const geometry = useMemo(() => makeGalaxy(60_000), [])
```

Без `useMemo` они пересоздавались бы на каждом рендере компонента.

## Смена сцен

```tsx
<Scene key={scene} />
```

`key` заставляет React размонтировать старую сцену целиком — R3F сам
освобождает её геометрии и материалы. Вспышка с названием сцены — обычный
DOM-слой с CSS-анимацией поверх холста.

## Ошибки

> **`setState` в `useFrame`.** 60 перерисовок React в секунду — тормоза. Меняйте объекты three.js
> напрямую через `ref`.
>
> **Создавать геометрию и материалы в теле компонента.** Каждый рендер — новые объекты на
> видеокарте. `useMemo`.
>
> **Анимация «на кадр»** (`rotation.y += 0.01`). На 120 Гц — вдвое быстрее. Умножайте на `dt`.
